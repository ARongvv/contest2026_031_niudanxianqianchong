# SmartHome 旧页面迁移

## 阶段一：设置与服务入口

- 删除旧设置、旧“更多”及模型、工具、MCP、Node 独立服务页，移除旧控件字段和隐藏 MCP 定时器。
- V9 工具权限直接枚举完整注册表，显示来源与可用性；聊天占用锁时立即提示忙碌，更新失败恢复开关。
- MCP 增加发现／重试、连接状态刷新与当前参数回填；后台应用配置，失败保留原桥接实例、工具白名单和自定义请求头。
- KWS 唤醒开关迁入语音服务，后台保存、失败回退；ASR/TTS 未编译时也能进入 KWS 设置。
- TTS 恢复“停止播报”操作。

MCP 地址修改仅本次运行有效；初始化仍要求有效的 `mcp_bridge.json` 及工具白名单，凭据从 `secrets.json` 读取。

验证：真实 LVGL 控件回归 20 项、真实 MCP 构造器回归、Agent ASan/UBSan 回归。测试使用服务替身，没有连接真实 MCP 服务、操作设备或烧录。

P4 对象检查在当前非 SmartHome 配置下缺少导出的 `netutils/cJSON.h`，未完成；不将主机验证视为固件或板端验收。

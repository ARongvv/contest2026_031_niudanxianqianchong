## 1. 总则

- 所有资源维护一套**设计源**（SVG / 高分辨率 PNG / 字体源），真机只部署按目标尺寸裁剪、
  压缩后的导出产物；不接收未授权品牌素材、截图或网络抓取资源。
- 图标以 24×24 设计网格为基准，逻辑 ID 使用小写 `snake_case`，不带分辨率和格式；
  文件名追加 `_20` / `_24` / `_48` 等尺寸后缀。
- 单色图标优先转 LVGL 4 bpp 内嵌图标字体；运行时应用主题色，不为亮/暗主题各存一张图。
- 复用现有 25 个 PNG 前必须确认深色主题（#161819 背景）下的对比度；200×200 源图不得
  直接缩放后充当 20 px 状态栏图标。
- “复用”一栏的含义：✅ 可改造复用（需裁剪/改色/补状态）；❌ 需新设计。

完整 MiSans 约 7.9 MiB/字重，严禁进入当前 1 MiB LittleFS 分区；新增设备名/场景名
进入产品文案前必须先跑字集检查，缺字降级并记录，不得在线下载字体。

## 10. 明确不做（S6 边界）

- 摄像头预览帧、AI 检测框、实时天气数据图、专辑封面：属 Vision Service / 业务数据，
  不进资源包；QuickApp Store 不保存帧字节或 Base64。
- 每设备一张彩色大插画：不做，设备身份由 S2 图标组合表达。
- 全天候动态壁纸、GIF、滚动大图、同屏多层半透明 PNG：超出性能预算，首期不引入。
- 任何第三方产品的图标、壁纸、截图、文案。

## 12. 待决项

1. **场景插画风格**：纯渐变几何（成本最低，可代码产出）/ 自制矢量插画 / 授权插画库。
   决定 S4 张数与 280 KiB 预算是否成立。首期不可使用外部产品视觉素材。
2. **时钟大数字实现**：TinyTTF 动态渲染（需实测大字号内存与首帧耗时）还是预生成
   LVGL 数字字库；与视觉资源方案 §10 待决项 2 联动。
3. **房间图标**：首期确认只保留文字 Tab，不设计 6 个房间图标；
   `icon_room_living` / `icon_room_bedroom` 仅留作二级页头候选。
4. **告警图标深度**：6 个 AI 事件是“图标 + 文字”还是“纯文字徽章 + 颜色”；
   前者符合无障碍要求但增加设计量。
5. **图标来源与责任人**：设计工具、许可证登记责任人（同视觉资源方案 §10 待决项 3）。

## 13. 下一步（对应 R0 资源底座）

1. 建立 `ui-assets/manifest/assets.json`，将本清单全部条目录入，补齐许可证、画布、

2. 建立 `chars.txt` 初版（本清单全部文案 + 原型页面文案）；
3. 对现有 25 个 PNG 逐项给出处置结论；
4. 确认 §12 待决项 1、3 后，冻结 P0 范围（约 30 个图标 + 4 场景插画 + 2 字重字体）。

# 基于 cAGENT 的 ESP-IDF 智能家居系统参赛文档

## 作品名称

慧居 Agent：基于 ESP-IDF 与 cAGENT 的大模型智能家居中控系统

## 作品关键字

ESP32-S3、ESP-IDF、cAGENT、AIoT、智能家居、大模型工具调用、环境感知、LVGL、人机交互、节能控制

## 应用领域

智能家居、智慧社区、居家康养、低碳节能、家庭安全与物联网边缘控制。

## 作品创意（500 字以内）

本作品面向普通家庭中“设备多、控制分散、自动化规则难配置”的痛点，设计一套运行在 ESP-IDF 平台上的大模型智能家居中控系统。系统以 ESP32-S3 为核心主控，接入温湿度、环境光、人体存在等传感器，并通过 cAGENT 将云端大模型的自然语言理解能力与本地设备控制工具连接起来。用户可以像聊天一样说“我要睡觉了”“客厅太暗”“卧室有点闷”，系统会结合实时环境数据、设备状态和家庭场景策略，自主判断是否查询状态、调整灯光、开启空调、设置定时或给出节能建议。与传统固定规则智能家居相比，本作品强调“可解释的 Agent 控制链”：每次模型推理、工具调用和设备反馈都能在屏幕或调试界面中展示，便于用户理解和开发者调试。作品既可作为家庭中控屏，也可扩展为社区、宿舍、养老看护等场景的低成本 AIoT 控制节点。

## 技术架构

### 1. 感知层

- 主控芯片：ESP32-S3，负责传感器采集、网络连接、UI 刷新和本地控制逻辑。
- 环境传感器：温湿度传感器、环境光传感器、人体存在/红外传感器，可通过 I2C、GPIO、ADC 或 UART 接入。
- 设备对象：灯光、空调、插座、窗帘等智能设备。比赛阶段可先使用继电器、LED、PWM 调光、舵机或虚拟设备模拟。
- 数据融合：将温度、湿度、光照、人体存在、设备状态统一整理为家庭状态 JSON，供 cAGENT context 和 `get_home_status` 工具读取。

### 2. 传输层

- 本地通信：GPIO、I2C、UART、PWM、BLE Mesh 或 Matter 设备控制接口。
- 网络通信：ESP-IDF Wi-Fi 连接家庭路由器，通过 HTTPS 访问云端大模型服务。
- 可扩展通信：支持 MQTT/HTTP 上报状态到云平台，也可通过局域网协议接入 Home Assistant、Matter Bridge 或自建网关。

### 3. 控制层

- cAGENT 作为嵌入式 Agent 核心，负责 ReAct 推理循环、上下文拼装、工具注册、工具调用和事件回调。
- 本地工具包括 `get_home_status`、`set_light`、`set_ac`、`run_scene`、`set_timer`、`get_weather` 等。
- 工具安全策略：只暴露白名单工具；设备控制工具限制参数范围，例如亮度 0-100、空调温度 16-30；环境传感器数据只允许读取，不允许由大模型伪造写入。
- 控制流程：用户输入或传感事件触发 Agent，模型决定是否调用工具，本地工具执行设备动作，结果回写给模型并生成最终回复。

### 4. 软件及开发环境

- 开发框架：ESP-IDF，使用 C 语言实现主控逻辑、驱动适配和 cAGENT runtime。
- Agent 框架：cAGENT，移植 ESP-IDF runtime，复用 OpenAI-compatible 后端、工具调用、Skill、context provider 和事件链路。
- UI 框架：LVGL，用于家庭中控屏，展示设备面板、聊天窗口、模型设置、工具调用链和错误状态。
- 配置管理：通过本地配置保存模型 host、path、model、API key、timeout 等参数，支持多 LLM 后端切换。
- 调试方式：串口日志、LVGL trace card、cAGENT event callback、工具调用耗时统计。

### 5. 云应用

- 云端大模型：接入 DeepSeek、通义千问、Kimi、OpenAI-compatible 服务或私有模型网关。
- 云端能力：自然语言理解、场景推理、设备控制计划生成、节能建议、天气与日程信息融合。
- 数据边界：设备原始控制仍在本地执行；云端只接收必要的状态摘要和用户请求，API key 不在日志和 UI 明文展示。
- 后续扩展：接入物联网云平台，实现远程状态查看、策略同步、设备 OTA、家庭能耗趋势分析。

## 其他内容

- 创新点：把大模型 tool calling 与嵌入式本地设备控制结合，让智能家居从固定规则升级为可对话、可推理、可解释的 Agent。
- 实用价值：适合家庭节能、老人看护、宿舍管理、办公室环境控制等场景。
- 可落地性：核心链路已在 cAGENT smart_home demo 中验证，后续重点是将虚拟设备层替换为 ESP-IDF 传感器驱动和真实执行器。
- 展示方式：现场可演示语音/文本输入、实时环境变化、自动调光、空调控制、睡眠/离家场景、工具调用链可视化和多 LLM 后端切换。

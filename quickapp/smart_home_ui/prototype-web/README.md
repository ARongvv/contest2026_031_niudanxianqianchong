# SmartHome 网页交互原型

这是根据 `docs/开发计划/应用与AI/ESP32-P4X-智能家居中控面板UI设计方案.md` 制作的
1024×600 横屏网页 Demo。当前默认展示低饱和浅色主题；主题只服务于视觉原型，不代表 P4X
真机的最终渲染资源方案。

## 使用方式

无需安装依赖，直接用浏览器打开 `index.html` 即可。浏览器窗口小于设计画布时，页面会等比
缩放预览。

初始界面为低干扰屏保。向上滑动（桌面端可鼠标上拖，或按 `↑` / 空格）进入首页；首页采用
左侧天气环境大卡与右侧两行异构功能卡布局，不提供卡片编辑、删除、添加或拖动重排。随后可
验证空间切换、底部导航、设备开关、场景执行、安防提醒与 Agent 异步回复。

## 边界

- 所有状态均为网页内 Mock Store，仅用于验证信息架构和交互节奏。
- 未来 QuickApp 应以 `system.smarthome` 的 snapshot/event 更新同等页面状态。
- CSS 阴影、渐变和动画表达视觉意图；P4X 真机须按 30 FPS、PSRAM 与摄像头资源预算降级。
- `assets/icons/` 为网页原型导入的单色 PNG 图标（当前 61 个）；它们以原尺寸保留，P4X
  LVGL/QuickApp 真机接入时仍须导出为 24/32/48 px 的目标资源。
- `assets/icons/` 是用户提供、仅用于当前网页原型评审的素材。其来源与许可证尚未登记，
  在确认授权前不得打包进 P4X 固件、QuickApp RPK 或比赛提交物；其余页面不复制第三方
  产品的图片、壁纸或文案。
